# IL-Y (Taxi Cyprus): итоговый аудит и план завершения

Состояние на 2026-10-01. Отчёты 7 аудиторов сведены в один: security, backend, QA, UX, product, regulatory, ops. Аудит был только на чтение: я ничего не менял, не коммитил и не деплоил.

**Что проверено мной лично.** Все P0 я сверил с кодом: `src/lib/config.ts:37`, `src/server/sms.ts:38`, `src/lib/http.ts:59-67`, `src/server/quote.ts:95-100`, `src/app/privacy/page.tsx:4-8`, `src/lib/eligibility-policy.ts:6`, `BookingApp.tsx:461,557,581`, `health/live/route.ts:43`, `Dockerfile:46-47`, `deploy/backup.sh:1,10`, `deploy/nginx-*.conf:13-14`. Все подтвердились.

**Тесты.** Их прогонял только QA-аудитор во временной Postgres, не в проде. Итог: vitest 107 passed / 1 skipped / 0 failed, `tsc --noEmit` без ошибок, `prisma migrate deploy` на чистой БД проходит. Остальные выводы получены чтением кода и GET-запросами к live. Подделку X-Forwarded-For против live никто не отправлял.

## Разрешённые противоречия
- **Файл `Git` в репозитории.** Security подозревал, что там токен. Ops пишет, что там только URL репозитория. Я проверил по шаблону, не выводя содержимое: признаков токена (`ghp_`, `github_pat_`, `user:pass@`) нет, строка целиком совпадает с `https://github.com/<owner>/<repo>`. Это не находка, вопрос закрыт.
- **Насколько серьёзен обход rate limit через XFF.** Security поставил P1, QA и Ops поставили P0. Я оставляю **P0**. Логика `idx = len - hops - 1` при `hops=2` действительно выбирает значение, которое подставил клиент. Ошибка открывает перебор OTP и бесконтрольные расходы на Google API, а после подключения Twilio ещё и SMS-pumping.
- **Утечка OTP.** Security и QA разошлись в номере строки: `config.ts:32` против `:37`. Правильно `config.ts:37`: `DEMO_MODE || 'true'`, то есть по умолчанию флаг включён.
- **Фиксированные тарифы из аэропорта.** Product ставит P0, regulatory ставит P1. Я оставляю **P0 для публичного запуска**, но не для беты. Расхождение с официальной таблицей около 28% на маршруте LCA→Limassol, а подаётся сервис как «честное такси».

## Executive summary

**(a) Продолжение беты: можно, но после одного срочного исправления.** Сейчас на публичном URL любой анонимный пользователь получает OTP-код прямо в ответе API (`DEMO_MODE=true`, `sms.ts:38`). Зная номер телефона, можно войти как любой водитель или пассажир. Номер водителя пассажир видит в трекинге (`views.ts:72`). Это действующий обход аутентификации. Закрывается за час: ограничить `devCode` allowlist'ом тестовых номеров или выключить `DEMO_MODE`. Также нужно исправить `TRUSTED_PROXY_HOPS`. Остальное ядро крепкое: guard'ы на всех 87 роутах, IDOR не найдено, блокировки `FOR UPDATE`, outbox, идемпотентность.

**(b) Публичный запуск на Кипре: не готов.** Блокеры трёх видов:
1. **Юридические.** `/privacy` и `/terms` остались заглушками, и часть их утверждений не соответствует коду. Водители со статусом `LEGACY` получают заказы без проверенной лицензии и страховки. В аэропорту нет фиксированного тарифа. Не учитываются район и тип лицензии.
2. **Эксплуатационные.** Нет мониторинга и алертов. Остановку autonomous dispatch никто не заметит. Бэкап может молча записать пустой файл.
3. **Безопасность.** Обход rate limit, не атомарный limiter, у админов только пароль и общий `DEMO_PASSWORD`, origin доступен напрямую, хост на Ubuntu 20.04 без ESM.

По UX: экран review противоречит автономной модели («Confirmed by dispatcher»), нет EL/RU, документы KYC с телефона не проходят лимит nginx в 2 МБ.

Оценка: часть «код (могу сделать сам)» занимает примерно 3–5 недель. Параллельно нужны юридические решения владельца.

## Stage 1: до публичного запуска (P1)

**Безопасность и инфраструктура**
1. **Атомарный rate limiter**: `INSERT … ON CONFLICT DO UPDATE … RETURNING`, отдельная таблица, очистка в maintenance. То же для счётчика попыток OTP. Сейчас параллельный burst засчитывается примерно как одна попытка, а строки `ratelimit:*` в `Setting` растут без ограничения. Evidence: `src/lib/rate-limit.ts:20-37`, `src/server/sms.ts:61-66`, `maintenance.ts:17,38`. M, код.
2. **Admin и dispatcher**: MFA (TOTP или WebAuthn) или Cloudflare Access на `/admin`. Сменить всем seeded-аккаунтам общий `DEMO_PASSWORD`, поднять `sessionVersion`. Evidence: `auth/login/route.ts:10-37`, `prisma/seed.ts:18-29`. M, код плюс владелец (новые пароли, Access).
3. **Origin**: закрыть 80/443 для всех, кроме Cloudflare (или Authenticated Origin Pulls), 301 на https, HSTS, CF Full (strict) с Origin CA. Evidence: `deploy/nginx-cyprustaxi.conf:6-8`, ufw 80/443 Anywhere. S, владелец (общий хост, настройки CF).
4. **Ubuntu 20.04 без ESM**: подключить Ubuntu Pro, затем перенести IL-Y на отдельную VM с 22.04/24.04. На хосте также работают winzilla, agora и supporthub. M, владелец.
5. **`backup.sh` проходит при упавшем `pg_dump`** (`#!/bin/sh` + `set -eu` без pipefail, `deploy/backup.sh:1,10,25`). Перейти на bash с `pipefail`, проверять минимальный размер и `pg_restore --list`, добавить dead-man ping, восстановление по таймеру. S, код.
6. **Деплой и откат**: образы с тегом `:<git-sha>`, `scripts/deploy.sh` (бэкап, миграции one-shot, health gate, авто-откат), CI в GitHub Actions (tsc, vitest на Postgres service, build, npm audit). Evidence: `docker-compose.yml:75` (только `:latest`), `deploy/entrypoint.sh:15`, нет `.github/`. M, код.
7. **nginx `client_max_body_size 2m`**, а приложение принимает до 10/20 МБ, поэтому KYC-фото с телефона падают с 413. Evidence: `deploy/nginx-cyprustaxi.conf:13`, `nginx-il-y-taxi.conf:14`, `src/server/storage.ts:10-11`. Поднять лимит на роуте документов и/или сжимать в браузере. S, код.

## Идеи продукта и дифференциации (топ-7)
1. **«Official fare, no surge, licensed only»**: фиксированный тариф из аэропорта плюс неизменяемый чек. Прямой ответ на жалобы на переплаты в 2025 году (argophilia.com).
2. **Airport pre-assign с отслеживанием рейса**: водитель назначается заранее, учитываются задержки. Это конкурирует с трансфер-брокерами, а не только с Bolt.
3. **Выгодная для водителей модель**: фиксированная недельная плата или 0–10% против 15–20% у Bolt, наличные остаются у водителя. Ограничивает рынок предложение водителей, а не спрос.
4. **Языки водителя на карточке** и UI на EN/EL/RU (позже HE/PL). Дёшево и важно для Лимасола.
5. **Набор безопасности**: share-trip, 112, рейтинг и фото, start code. Работает на доверие к новому бренду.
6. **B2B через отели, виллы и relocation-агентства** с QR-кодами. Даёт стабильный спрос на фоне спада туризма в 2026 году (−25–30%).
7. **«Favourite driver» и referral** после появления карточной оплаты. Удержание без дорогих скидок.

Рекомендуемый go-to-market: старт в одном районе (Limassol) с 20–40 лицензированными водителями, затем LCA с водителями, допущенными в этом районе, затем PFO к сезону.
